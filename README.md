## 설치
- `SKILL.md` 다운로드. `/.claude/skills/rocky` 폴더에 넣는다.
- `/rocky`, `Rocky mode`, `talk like Rocky`, `use Rocky`로 로키 모드 시작한다.
- 광기 멈춤: `stop rocky` 또는 `normal mode` 써라.
